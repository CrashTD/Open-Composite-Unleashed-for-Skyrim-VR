# Changelog

## v4.2.9 - 28 Aug 2026

Changes since the Nexus build uploaded 22 Aug 2026 at 3:17 PM.

- Expanded the installed Help webpage with a complete tab-by-tab Configurator reference covering Settings, Bindings, Gestures, Video and its Advanced panels, SteamVR / Help, Haptics, and experimental Body Tracking. The reference separates saved settings from actions and explains restart requirements, performance/quality tradeoffs, calibration scope, MIP bias, VRS fallback behavior, and unsafe feature combinations. The guide now uses the same graphite surfaces, bright-green interaction glow, rounded pill controls, and softened warning colors as the Configurator.
- Cleaned up Skyrim VR Settings so the controls describe their real behavior: Input Smoothing is now Input Dropout Protection with a Hold Samples control, One Euro filter tuning uses readable base-frequency/response labels and detailed tooltips, physical trackpad routing is distinguished from thumbstick emulation, and the controller-sleep option now explicitly says it keeps the player's hands instead of allowing a temporary Vive-wand replacement. Removed the non-functional GPU Frame Timing checkbox and its disabled D3D11 timestamp-query code, which had previously been shelved for causing micro-stutter. Older `enableGpuTiming` entries are ignored and removed when the Configurator saves.
- Fixed AMD and other non-NVIDIA systems repeatedly attempting to initialize the NVIDIA-only VRS backend every compositor frame while Eye Tracking AUTO was enabled. OCU now identifies the D3D adapter before touching NVAPI and permanently latches an unsupported result for that graphics-device session. Generic OpenXR eye-gaze handling, FSR, DAPA, menus, and keyboards are unchanged.
- Keyboard Studio now treats PC/VR Mode and Lock/Unlock as layered controls. Their interaction box, state PNG, and text can be selected and positioned independently; state PNGs can also be resized and text retains independent font scaling. The native keyboard applies those exact transforms while keeping the authored interaction box as the sole laser hit target. Existing `.kb` and `.ocukb` designs remain centered through zero-offset/inherited-size defaults.
- Fixed selection authority for those layered controls: choosing a state PNG now selects its matching preview/image immediately, explicit Hit box / State image / Text buttons expose fully overlapped layers, and clicking a painted PC/VR or LOCK glyph takes text authority even while its larger hit box is selected. Moving or resizing a hit box now preserves the state image and text at their absolute visual geometry instead of stretching them; Fit image to box and Fit box to image provide deliberate one-shot alignment in either direction. The mouse wheel resizes selected state images or ordinary sprites around their center as well as resizing selected text. A selected generic sprite can also be dragged when it overlaps a Mode/Lock hit box.
- Added four optional state-aware top-button images to Keyboard Studio and the native keyboard: VR Mode, PC Mode, world/unlocked, and head-locked. Each PNG follows the authored button rectangle, switches with the actual runtime state, falls back to normal text when absent, and can optionally retain text over the image. The assets travel inside `.ocukb` and MO2 exports and are composited into the existing keyboard texture without adding an OpenXR layer or swapchain.
- Replaced the keyboard and Scaleform-menu laser endpoints with PrismaUI-style faded circular dots: a warm-white core, soft warm halo, and transparent edge. The texture is now correctly premultiplied, fixing the square quad some runtimes exposed around the cursor. Click feedback retains the electric-blue version of the same shape.
- Kept the cursor change within the existing keyboard/menu dot layers; it adds no OpenXR composition layers or SteamVR overlays.
- Removed the keyboard breathing renderer's per-tick D3D texture allocation and extra GPU copy. OCU now reuses its CPU surface, updates the acquired OpenXR swapchain image directly, and samples slow breathing effects at 10 Hz instead of rebuilding the full 1024x560 keyboard at 20 Hz. Glow and breathing remain available.
- Cached repeated rounded-key glow geometry, collapsed sixteen redundant font-glow layout/resampling passes into one atlas pass, and added a native-size fast path for stock keyboard backgrounds. Breathing, hover, and press effects retain the same keyboard layer while doing substantially less render-thread work. Slow keyboard refreshes are reported at most once every five seconds with CPU and OpenXR wait/upload time separated.
- Fixed the stock VR keyboard collapsing headset performance while a laser was active. Laser motion now updates a tiny dedicated cursor composition layer instead of forcing a CPU redraw, swapchain wait, and upload of the full 1024x560 keyboard every frame. This path is isolated from the Quest Pro companion-window/mirror fix, DAPA, render scale, and CSX.
- Kept flat-menu laser pose/rendering at full headset refresh while making Scaleform interaction change-driven. Moving hover is capped at roughly 30 Hz, a stationary pointer performs no Scaleform hit testing or mouse-event injection, and menu transitions, trigger edges, and active drags bypass the limiter immediately. Slow semantic probes over 4 ms are logged at most once every two seconds.
- Physically removed the obsolete MapMenu depth bridge, cloned companion-beam geometry, shader/material mutation, GPU buffer replacement, map quad profile, and dormant map-specific laser branches. Only a menu-name lifecycle sentinel remains so OCU can clear its own state and leave Skyrim VR's map completely alone.
- Added directly editable and pasteable hex color fields beside Keyboard Studio's color-wheel swatches. Both `#RRGGBB` and alpha-preserving `#RRGGBBAA` values are accepted.
- Fixed the Appearance palette retaining stale colors after changing Keyboard Design or Base Theme. The palette now always reflects the loaded design, appearance edits automatically create overrides without a gate checkbox, and a Reset action restores the selected Base Theme. Switching designs explicitly warns before discarding unsaved changes.
- Restored native cut/copy/paste and undo behavior inside Studio's text and numeric editors. Selecting a key now has a real drag threshold, preserves exact values such as `1.15` with Snap enabled, and no longer lifts the key or glyph as an edit-mode hover preview.
- Added a Configurator warning when Press, Double Tap, Triple Tap, or Quad Tap actions share the exact same controller input. These modes remain independent by design; OCU explains that exclusive recognition would delay the shorter action for the full tap window instead of silently adding controller latency.
- Moved high-frequency DLSS, FSR3, motion-vector, and live-gaze telemetry behind the explicit `logLevel=debug` setting. Normal logging retains startup state, failures, first-frame confirmation, and slow-frame warnings without continuously writing render-path diagnostics.
- Cleaned the packaged `opencomposite.ini` so new installs receive the standard keyboard size, opacity, position, laser-adjustment, and VRIK preset defaults instead of development-machine values.
- Removed duplicate Keyboard Design entries caused by older managed copies sharing a bundled design name. The current stock design now wins and appears once under its clean name, including `Pug Dragon Keyboard`.
- Fixed authored settings arrows being visually covered but laser-blocked by invisible keyboard regions. Arrow hit testing now follows the renderer's topmost order, correcting the Dwemer opacity-up triangle that previously responded only when aimed just above it.
- Fixed Dwemer theme switching in Keyboard Studio so Size, Opacity, and Tilt move into the same authored side-panel slots used by the in-game Dwemer keyboard. The stock design now also preserves Dwemer's distinct arrow, label, value, and control-box spacing. The Controls inspector and preview update immediately, and exact runtime geometry is covered by Studio's self-test.
- Added a Find Fonts shortcut beside Keyboard Studio's Add TTF action, with a reminder to verify the individual font's redistribution license before sharing it in an `.ocukb` or mod package.
- Added a dedicated Relos Custom Controllers pill button to Keyboard Studio. Its tooltip identifies the linked mod as SteamVR controller artwork and clarifies that it does not change OCU bindings, dot calibration, or laser alignment.
- Widened the Configurator's selected-controller-button prompt and moved the adjacent Action field so `(click a button)` remains readable instead of being clipped.

- Matched the Configurator's Open Keyboard Studio action to the exact positive-button green used elsewhere and added a one-second diagonal sword-shine sweep every five seconds.
- Removed pointer-drag stalls by coalescing full 1024x560 preview rendering and deferring inspector-panel rebuilds until the drag is released.
- Added visible-item marquee selection from empty canvas space, additive Ctrl/Shift marquee selection, per-item/group outlines, and group movement.
- Hidden plates are excluded from marquee selection. Full-canvas backgrounds are selected only when completely enclosed so they do not capture every box.
- Renamed the misleading Grid Width section to Grid Column Count and documents that fewer columns produce larger keys.
- Removed the zero-position clamp from typing-key numeric fields, pointer movement, multi-selection movement, and edge resizing. Negative grid X/Y positions now work end to end.
- Preview/input bar, PC/VR Mode, and Lock now have independent plate width, plate height, and font scale. Visible plates resize with canvas handles, the mouse wheel scales their font, and native OCU rendering plus laser hit testing use the authored rectangles.
- Fixed Base Theme showing the raw `KeyboardTheme` record instead of readable theme names. Added an explicit explanation that custom colors/artwork override most theme visuals while fallback styling and geometry remain.
- Moved Undo and Redo from the top action row to a dedicated lower-right strip beneath the keyboard preview; the live history count remains in the bottom status bar.
- Added cursor-anchored 100%-500% canvas zoom: when text is selected the wheel resizes that font anywhere on the canvas; selecting a non-text element makes the wheel zoom the full keyboard, and middle-drag pans for pixel-level work.
- Fixed Use custom keyboard colors replacing stock-template colors with hidden green defaults. Its first enable now seeds editable colors, outline behavior, roundness, and effects from the currently visible Base Theme; later off/on toggles restore the user's custom values.
- Replaced the stock Dwemer Keyboard Design with the latest `Dwemer.ocukb` layout under the same Dwemer name. The design now uses OCU's bundled Dwemer Base Theme background and loose layout data, so the Nexus package contains no nested archive.
- Added Pug Dragon as a second bundled artwork-backed Keyboard Design in both Studio and Configurator while leaving Parchment first and permanently default.

## v4.2.6 - 22 Aug 2026

Changes since Nexus v4.2.5, uploaded 16 Aug 2026 at 3:11 AM.

### Community Shaders / CSX Compatibility

- Removed OCU's MapMenu integration completely. OCU no longer renders a map beam or dot, reads native pointer depth, exports map geometry, calls MapMenu Scaleform, or masks map input. Skyrim VR's original map laser and controls remain fully native.
- Both controller lasers now remain visible at matching full strength in flat menus, including MCM and RaceMenu. Skyrim's single menu cursor follows the last laser meaningfully moved on the menu quad; clicking also transfers ownership immediately. A motion dead zone prevents tracking jitter from making stationary hands fight, and ownership stays locked through slider, scrollbar, and RaceMenu sculpt drags until the original hand releases.
- Fixed a delayed MapMenu/fast-travel crash that produced the same poisoned `MapZoomHandler`/`MapLookHandler`/`MapMoveHandler`/`MapClickHandler` pointer signature both with and without Community Shaders.
- Added single-flight guards to OCU's game-thread laser, console-pick, and render-target refresh jobs, and limited expensive menu work to one pass per submitted frame or menu transition. A blocked menu frame can no longer accumulate or repeatedly execute hundreds of stale pumps and then run at one frame every 5–10 seconds.

### Movable Keyboard Top Bar

- Made the text bar, PC/VR Mode button, and Lock button independently selectable and movable in Keyboard Studio, with exact numeric X/Y offsets.
- Saved top-bar positions now drive both native rendering and native laser hit-testing, so interactive regions follow the moved controls in game.
- Added independent plate-visibility switches for ordinary keys, the PC/VR Mode plus Lock buttons, and the input bar. Hidden top plates retain their exact native laser/caret hit areas.
- Promoted Undo and Redo to the main Studio toolbar, kept the global Ctrl+Z/Ctrl+Y shortcuts, capped snapshots at 150, and added a persistent undo/redo history counter in the status bar.
- Fixed click-only canvas selections creating identical history entries. Undo/Redo now skip legacy no-op snapshots, preserve the selected object, and repaint the restored keyboard immediately.
- Added a separate Keyboard Design library in Studio. Built-in and previously opened/saved `.kb` designs appear in its dropdown; Save and Save As register self-contained managed copies automatically so designs saved from the same folder cannot overwrite one another's artwork, while Install to OCU remains an explicit action.
- Kept Undo and Redo text bright white when their history stacks are empty instead of allowing the WinForms disabled renderer to turn them black.
- Added the shared Keyboard Design dropdown to the main Configurator with Parchment as the permanent default. Designs opened or saved in Studio automatically populate this list; Save installs the selected `.kb` and referenced artwork into the OCU root, while selecting Parchment switches back to the embedded keyboard without deleting the custom project.

### Keyboard Arrow-Key Editing

- Reworked Keyboard Studio's Key page around a physical-key capture button. Click Assigned key and press a real key; Studio translates normal and Shift output through the active Windows keyboard layout instead of exposing raw OCU escape fields.
- Corrected the bundled number row to use `Shift+3 = #` instead of the British pound sign, and changed the grave key's shifted symbol to `~`.
- Renamed label placement to Font X/Y and Font size/scale, replaced the ambiguous Layout block with a documented Grid Width/Columns control, removed the duplicate inspector Undo/Redo buttons, and removed the exposed Stretch-to-right checkbox. Editing an old stretched key's width now converts it to an explicit width without jumping.
- Renamed Appearance's Key Shape section to Interaction / Selection. Hidden key or top-control plates are now click-through in Studio instead of leaving large invisible draggable regions; visible glyphs remain directly selectable and native in-game assignments remain intact.
- Matched Studio to the Configurator's exact dark-green palette, glowing anti-aliased pill buttons, green checkboxes, Segoe UI typography, and selected-tab treatment. The inspector now opens wide enough to show Key, Appearance, Artwork, and Controls without a tab-scroll arrow.
- Fixed the keyboard's Up, Down, Left, and Right key triangles so each one uses its own authored content offset and scale in both Studio and the VR keyboard.
- Arrow-key content can now be dragged, mouse-wheel scaled, or resized with handles instead of filling the entire key plate.
- Fixed translucent plate outlines and glows bleeding through the entire key fill. Fill now paints only the interior, outline is a true border ring, and glow is confined to rings outside the plate in both Studio and VR.
- Made the classic Parchment spacebar ribbon optional and directly selectable as key content. It can be moved, scaled, resized, removed, cut, or copied as PNG artwork in Studio, while the untouched embedded Parchment keyboard keeps the ribbon by default.
- Removed the unnecessary OCU-folder prompt when Studio is launched from an installed OCU package. Save, Save As, and Apply to Game now detect that package's sibling `root` folder, write the active keyboard there, and set `layout=auto`; the folder picker remains only as a standalone fallback.

### PSVR2 Sense Controller Translation

- Enabled the ratified `XR_KHR_generic_controller` extension when the runtime advertises it.
- Added a full generic-controller interaction profile for PSVR2 Sense and other unmapped motion controllers: primary/secondary buttons, thumbsticks, triggers, grips, poses, and haptics now translate into Skyrim VR's Oculus-compatible legacy input surface.
- The new profile is preferred over the input-starved `khr/simple_controller` fallback without inventing Sony-private OpenXR paths.
- Added PlayStation VR2 Sense artwork to the Configurator controller selector, with PSVR-specific clickable positions, enlarged stick-click targets, and Square/Triangle/Cross/Circle labels. The picture is presentation-only; it does not alter the runtime binding translation.

### Eye-Tracked Foveated Rendering

- Added Skyrim Compatibility as the default pattern whenever VRS is active; it does not enable VRS or Fixed by itself. Eye Tracking AUTO defaults on and activates eye-tracked VRS only while a valid gaze stream exists. Fixed defaults off. Compatibility caps peripheral coarse shading at half-rate (2x1/1x2) to avoid the severe flat-color terrain and foliage failures caused by 2x2 derivative/mip behavior; 2x2 remains available through the opt-in performance presets.
- Removed the non-functional Outer Radius control. Older `vrsOuterRadius` entries are still accepted silently and are removed the next time the Configurator saves.
- Fixed choosing a foveated-rendering preset immediately changing the preset display back to Custom while its values were being applied.
- Hardened the standard `XR_EXT_eye_gaze_interaction` path for PSVR2Toolkit, Quest Pro, and other OpenXR runtimes/headsets.
- Valid gaze poses are now accepted when a conforming runtime reports sample time `0` (timestamp unavailable); freshness limits still reject stale or implausibly future timestamped samples.
- Added rate-limited gaze-state diagnostics plus live direction/per-eye UV diagnostics so hardware tests can prove that the VRS fovea is following the user's eyes.
- Auto eye tracking still never enables Fixed VRS on a headset without usable eye tracking. Fixed remains a separate explicit option.
- Eye tracking still does not modify CSX render scale, submitted texture bounds, swapchains, DAPA timing, motion vectors, or post-processing resources.

### PSVR / DAPA Performance

## v2.0.0

Major overhaul of the VR keyboard input system — thumbstick navigation replaced with laser pointer aiming, and the keyboard is now world-anchored and repositionable.

### New Features

- **Laser pointer beams** — Each controller projects a visible warm-white beam onto the keyboard surface with a cursor dot showing exactly where you're aiming. Point and pull trigger to type.
- **World-anchored keyboard** — The keyboard now spawns in world space in front of the player (80cm forward, 35cm below eye level) and stays fixed in place. No longer head-locked by default.
- **Grab bar** — A dedicated strip at the top of the keyboard lets you hold trigger and drag to reposition the keyboard anywhere in your play space. The keyboard follows your laser 1:1 during drag.
- **MOVE / LOCK buttons** — MOVE (top-left) indicates the keyboard is in world-anchored mode and can be grabbed. LOCK (top-right) toggles head-locked mode where the keyboard follows your head. Both buttons show hover highlights when aimed at.
- **Clickable text cursor** — Tap anywhere in the text input bar to place the cursor at that character position. A blinking cursor (500ms on/off) shows your insertion point.
- **Cursor-based editing** — Characters now insert at the cursor position instead of always appending to the end. Backspace deletes the character before the cursor.
- **Beam billboard orientation** — Laser beams always face the viewer for maximum visibility regardless of viewing angle.

### Changes

- Thumbstick/DPad key navigation removed (laser pointers replace it entirely)
- Keyboard spawns facing the player based on head orientation at open time
- Selection highlight is now a unified cream-gold color for both controllers (replaces the old blue-left/green-right scheme)
- Text bar is now a distinct clickable zone separated from the key area
- Warm white color scheme for laser beams and cursor dots (RGB 255/240/220)

### Technical

- Laser beams rendered as XrCompositionLayerQuad overlays (one per hand)
- Ray-plane intersection for keyboard hit testing supports arbitrary keyboard orientation
- Grab uses ray-plane intersection against the original grab plane to prevent feedback lag
- Head-lock toggle switches between viewSpace and floorSpace for both keyboard and laser layers
- Swapchain and D3D11 resources for laser beams properly created and destroyed (no leaks)

## v1.0.0

Initial release of the VR keyboard for Skyrim VR via OpenComposite.

### Features

- Native OpenXR composition layer keyboard
- Head-locked positioning (keyboard follows head movement)
- Thumbstick navigation between keys
- Trigger to press keys, grip to dismiss
- Dual controller support (blue highlight left, green highlight right)
- Skyrim-themed dark stone and gold UI
- Shift, Caps Lock, Backspace, Done keys
- English (GB) layout
- Works with character creation, enchanting, and any SteamVR keyboard API call
